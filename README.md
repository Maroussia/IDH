# Introduction to Digital Humanities (IDH)

This repository contains the course material for the **Introduction to Digital Humanities (IDH)**, a first-year, first-semester course in IE University's BA in Humanities.

## Course Overview

The course introduces students to the theory and practice of Digital Humanities, with a hands-on focus on Python programming for humanistic inquiry. No prior coding experience is required. By the end of the course, students will be able to:

- Understand key concepts and debates in Digital Humanities.
- Write basic Python code to analyse textual and tabular data.
- Use computational methods to explore humanities research questions.

The notebooks will use data from the Project Gutenberg (PG, https://www.gutenberg.org/).

## Repository Structure

```
├── Notebooks/
│   ├── *.ipynb          # Jupyter notebooks
│   ├── *.py             # Python files with questions and exercises loaded within the notebooks
│   └── PG/              # CSV files with selected metadata from PG
│   └── Other_files/     # Data for the exercises within the notebooks
└── README.md
```

## Getting Started

All notebooks are designed to run in [Google Colaboratory](https://colab.research.google.com/), a free, browser-based environment that requires no local installation, just a Google account.

To open a notebook in Colab directly from GitHub, click the **"Open in Colab"** badge at the top of each notebook, or paste the notebook's GitHub URL into Colab's **File → Open notebook → GitHub** tab.

If you do not have Google Colaboratory already listed in your Google Drive applications, you can find it in the available apps. Click on **New → More → Connect more apps +**.
